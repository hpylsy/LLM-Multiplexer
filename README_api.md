# PIONEER 战队 AI 中转站使用说明

本文档面向战队普通队员，介绍如何登录、查看自己的中转站信息，以及如何正确使用 API Key。

如无特殊说明，以下内容都以远端正式地址为准：

- 门户地址：[`http://154.201.92.23/`](http://154.201.92.23/)

---

## 1. 这是什么

[`PIONEER 战队 AI 中转站`](http://154.201.92.23/) 是战队内部统一使用的大模型中转门户，主要用于：

- 登录和查看个人账号
- 查看自己的 API Key
- 查看自己的调用记录
- 查看自己的额度情况
- 查看公开统计面板

你平时真正调用模型时，通常不是直接访问模型官方接口，而是通过战队提供的中转服务完成。

---

## 2. 登录前你需要知道什么

管理员会为你分配：

- 用户名
- 登录密码（同用户名）
- 已绑定的 CLIProxy API Key（在我的额度里查看url和API）

如果你还没有账号或无法登录，请联系管理员。

## 5. 如何查看自己的 API Key

当前系统中的 API Key 通常由管理员统一绑定。

如果后续开放“我的 Key”页面，你可以在那里查看；若当前页面未开放，请直接联系管理员获取你自己的中转 Key。

请注意：

- API Key 属于个人凭证
- 不要发到群里
- 不要提交到 GitHub
- 不要写进公开仓库

---

## 6. 如何使用中转站 API Key

你拿到自己的 Key 后，调用时核心信息通常包括：

- Base URL：由管理员提供的中转地址
- API Key：你的个人 Key

如果你使用的是兼容 OpenAI 的客户端，配置通常像这样：

```bash
BASE_URL=http://154.201.92.23:8317
API_KEY=你的个人密钥
```

不同工具填写位置不同，但本质上就是两项：

- 请求地址
- 身份密钥

如果管理员给你的不是这个地址，请以管理员实际通知为准。

## 11. 如果登录不上怎么办

请按顺序检查：

### 11.1 账号密码是否输对

尤其注意：

- 大小写
- 是否误加空格
- 输入法是否切换错误

### 11.2 地址是否打开正确

请确认你打开的是：

- [`http://154.201.92.23/`](http://154.201.92.23/)

而不是旧地址、旧端口或本地调试地址。

### 11.3 联系管理员重置密码

如果依旧无法登录，请联系管理员重置。

## 12. 如果 API Key 用不了怎么办

常见原因：

1. Base URL 填错
2. API Key 填错
3. 模型名填错
4. Key 已被禁用或替换
5. 你的客户端配置仍在用旧 Key

建议先做这些检查：

- 重新复制管理员发给你的 Key
- 核对地址是否为中转地址
- 确认你不是在使用旧的测试 Key

如果仍然失败，请把报错截图发给管理员。

---

## 13. 使用规范

请遵守以下规则：

- 不要泄露你的个人 API Key
- 不要把 Key 提交到代码仓库
- 不要把高频测试脚本长时间无控制运行
- 不要滥用高消耗模型
- 不要将其用于别的用途，仅供战队项目学习，后台监控到异常会禁用一个月API_Key并约谈
- 暂时不要用gpt-5.5，以及Google的大模型，推荐gpt-5.3-codex,gpt-4(不要滥用，很耗token)

---

## 14. 联系管理员时建议提供的信息

如果你遇到问题，建议一次性发这些信息：

- 你的用户名
- 出问题的大致时间
- 使用的模型名
- 报错截图

这样管理员会更快定位问题。

## 15. 队员常见问题 FAQ

### Q1：我有账号，但看不到我的使用记录？

可能原因：

- 你还没有实际调用成功过
- 你的客户端还在使用旧 Key
- 使用记录还没同步到你的账号下

### Q2：为什么我能登录门户，但 API 还是不能用？

门户账号和 API Key 是两套概念：

- 门户账号用于网页登录
- API Key 用于程序调用

你需要确认两者都已经分配到位。

### Q3：我能不能自己改密码？

不允许

### Q4：我能不能自己申请更多额度？

只要不滥用，无额度限制。
